\## Architectural Decisions



\### Decision 001

JARVIS will use a modular architecture rather than a monolithic application.



\### Decision 002

The AI provider will be abstracted behind a model gateway.



\### Decision 003

External actions will be performed through structured tools.



\### Decision 004

High-risk operations will pass through a permission and approval system.



\### Decision 005

Long-running operations will use explicit task states and cancellation support.

\## Definition of Done



A feature is not considered complete merely because code exists.



A feature is complete only when:



\- implementation exists

\- expected behavior works

\- failure behavior is handled

\- appropriate tests exist

\- security implications are considered

\- documentation reflects reality

\- regression checks pass
